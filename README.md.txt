# Bookstore Management System (Lab #4)

Система управління книжковим магазином з використанням PostgreSQL, Docker Compose та Python.

## 🛠 Технології
* **Database:** PostgreSQL 17
* **Containerization:** Docker & Docker Compose
* **Language:** Python 3.x
* **Database Driver:** `psycopg2-binary`

## 📁 Структура проєкту
* `docker-compose.yml` — конфігурація контейнера бази даних PostgreSQL.
* `console_app.py` — консольний додаток на Python для роботи з базой даних.
* `database/` — SQL-скрипти для створення таблиць, тестових даних та бізнес-логіки.
